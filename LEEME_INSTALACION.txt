CT CAMPEADOR · CONTROL DE PISTAS · V1.4
=======================================

NOVEDADES DE ESTA VERSION
-------------------------
1. Diseño visual más profesional y más cercano a una app real.
2. Uso del icono / escudo del club con nueva paleta de colores propia de Control de Pistas.
3. Opción de instalar visible nada más entrar en la aplicación.
4. Acceso únicamente mediante PIN de administrador.
5. Las reservas aparecen aunque el resultado todavía no esté confirmado.
6. No aparecen pistas futuras: solo franjas ya terminadas.
7. Se siguen excluyendo reservas canceladas, reprogramadas y partidos marcados como no disputados.
8. Mantiene la sincronización con la misma API / Cloudflare que la app principal.

INSTALACION
-----------
1. Sube TODOS los archivos del ZIP a la carpeta de tu PWA Control de Pistas en GitHub Pages.
2. Sustituye los archivos anteriores por los nuevos.
3. Espera a que GitHub publique la web.
4. Si la PWA instalada conserva caché, ciérrala y vuelve a abrirla o reinstálala.

COMO INSTALAR LA APP
--------------------
- Android / Chrome: usa el botón 'Instalar ahora' o el menú del navegador > 'Instalar app'.
- iPhone / iPad / Safari: Compartir > 'Añadir a pantalla de inicio'.

NOTA
----
Esta PWA está pensada para trabajar como herramienta auxiliar del administrador de CT Campeador.
